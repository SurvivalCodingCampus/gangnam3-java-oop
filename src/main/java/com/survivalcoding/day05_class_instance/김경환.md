## 3. 나만의 언어로 재해석한 핵심 용어 사전
- 접근제어자: 중요한거니까 함부로 바꾸지마라. (private: 오직 해당 클래스 내부에서만 접근할 수 있어 데이터 무결성 지킴(수정, 변경 임의로 못하게))
- 정보은닉: 객체의 내부 데이터를 외부에서 직접 보거나 함부로 수정치 못하도록 숨기는 것
- 클램핑: 특정 값이 허용하는 범위를 벗어나지 않게 강제로 가두는 연산 (최댓값, 최솟값 안에 경계안에 가두기) -> Math.max(min, Math.min(value, max)) 와 같은 형태로 구현 (경계값에 대한 걸까?)
- 생성자 오버로딩: 이름은 같은데 매개 변수의 개수나 타입이 다른 생성자 여러개 선언
- 초기화: 말그대로 default값을 만들어놔서 데이터가 null이나 0 등 비정상적인 상태로 객체가 돌아다니는걸 막는 과정
- 정적멤버: 인스턴스 1개도 생성 안했는데, 이용 가능한 착한 친구
