## 1. 오늘 내가 직접 손으로 치며 배운 점

- `Github Sync` : 해당 버튼 누르면 원본의 최신 버전을 가져와 합쳐짐 (조심)
- `object` : 현실 세계의 모든 객체
- `class` : 오브젝트를 가상세계 용으로 구체화 한 것
- `instance` : 클래스를 활용해 메모리 상에 만들어 낸 것
- `method` : 객체의 기능
- `함수` : 외부요인이 없는 기능 (단독으로 동작)
- `JavaDoc` : API 문서화 도구이자 주석 규칙
- `API (라이브러리 및 프레임워크 맥락에서)` : 다른 프로그램이나 개발자가 갖다 쓸 수 있도록 만들어 둔 명령어와 함수 집합

| 구분      | 프레임워크 (Framework) | 라이브러리 (Library)    |
| ------- | ----------------- | ------------------ |
| **주도권** | 프레임워크가 내 코드를 호출   | 내가 라이브러리 코드를 호출    |
| **역할**  | 전체적인 구조와 틀 제공     | 특정 기능 수행을 위한 도구 제공 |


- `float, double(실수 계산)` :
    - 오차가 있음, 정밀도가 낮음 (돈 계산에 사용 금지)
        - `오차 발생 이유` : 컴퓨터는 2진법을 사용해 실수를 표기하기 때문에 값이 나누어떨어지지 않고 무한으로 반복되는 현상이 발생해 근사치로 반올림해서 처리함
    - `소수를 10진수에서 2진수로 표현하는 방법` :
        - 딱 떨어질 때 까지 반복해서 2를 곱합
        - 딱 안 떨어지는 소수는 특정 자리에서 반올림

- 앱실론이라는 오차를 무시하는 식으로 해결가능

| 단계      | 코드                                       | 설명                 |
| :------ | :--------------------------------------- | :----------------- |
| **1단계** | double a = 0.1 + 0.2;<br>double b = 0.3; | 오차로 인해 차이가 발생      |
| **2단계** | double epsilon = 1e-10;                  | 10의 -10승까지 오차를 허용  |
| **3단계** | Math.abs(a - b) < epsilon                | 절대값을 구해 오차보다 큰지 비교 |
