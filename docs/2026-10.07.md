## 1. 배운 점

### 코틀린 소개

- 2011년7월 Jetbrains사에서 공개, 2016년2월 15일 1.0버전 릴리즈.
- 2017년 안드로이드 공식 언어로 지정, Null에 안전, 확장함수, 코루틴, JVM기반언어[2026-10.02.md](2026-10.02.md)
- JVM기반언어 - 자바 가상 머신(JVM, Java Virtual Machine)위에서 실행 될 수 있도록 만들어진 언어.

1. 세미콜론(;)의 퇴장과 간결함. 코틀린은 선택사항.
2. 변수 선언방식의 변화 (val(값 변경불가, 상수) VS var(갑 변경 가능, 변수))
3. 널 안전성(Null Safety)지원, 기본적으로 변수에는 Null을 넣을수 없게 막아두고, 꼭 넣어야 할때만 ?를 붙이게 강제합니다.
4. 함수 정의방식(public static void의 탈출) fun키워드 하나로 간단하게 함수를 만들 수 있습니다.
5. 조건문(Conditional Expressions) if는 단순희 문장이 아니라 값을 반환하는 표현식으로 사용.
6. 출력할때도 System.out.println대신 간단히 println을 씁니다.
7. 간결한 생성자 정의와 데이터클래스(DataClass)같은 편리한 기능을 제공합니다.

### 인텔리제이
- ** Alt + Enter ** : 오류 해결 제안
- ** Ctrl + Alt + L ** : 코드 자동정리
- ** Shift + Shift ** : 전체 검사
- ** Ctrl + B ** : 클래스 / 메서드 정의 이동
- ** Alt + Insert ** : 생성자 / Getter등 생성
