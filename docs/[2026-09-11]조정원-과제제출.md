# 인스턴스와 클래스
인스턴스는 클래스라는 규칙이나 기능으로 만들어진 산출물들입니다. 

## 용어 정리
- 객체와 함수: 객체와 함수는 둘다 동작을 담는 단위이지만 객체는 상태를 기억하기 때문에 결과가 달라질 수 있고 함수는 입력이 같으면 항상 같은 결과를 가져옵니다.  
- 클래스: 설계도/ 인스턴스: 설계도로 만들어진 것 중 하나/ 필드: 인스턴스의 값(name,hp)/ 메서드: 클래스 안의 함수(pray)
- package와 import: 내 클래스의 주소를 정할 때에는 package/ 남의 걸 단축해서 가져올 땐 import
