## 1. 배운 점

### 1. 동기 (Synchronous) vs 비동기 (Asynchronous)
- 동기 (Synchronous) vs 비동기 (Asynchronous)
  - 동기: 
    식당에 줄을 서서 내 차례가 올 때까지 꼼짝 않고 기다렸다가 밥을 받는 것 같아요.
    앞사람이 주문을 끝내야 내가 주문할 수 있습니다.   
  - 비동기: 
    카운터에서 진동벨(알림)을 받고 내 자리에 와서 장난감을 갖고 놀다가, 진동벨이 울리면 밥을 받아오는 것과 같아요! 
    기다리는 동안 다른 유익한 일을 할 수 있습니다.   
- 동시성 (Concurrency) vs 병렬성 (Parallelism)
  - 동시성: 
    혼자서 양손에 공을 번갈아가며 빠르게 던지는 저글링 같아요. 
    컴퓨터 안의 일꾼(코어)이 하나뿐이어도, 아주 빠른 속도로 여러 일을 번갈아가며 동시에 하는 것처럼 보이게 만듭니다.   
  - 병렬성: 
    친구와 내가 각각 양손에 공을 들고 진짜로 동시에 공을 주고받는 것 같아요. 컴퓨터 일꾼(코어)이 여러 개여서 진짜로 
    동시에 일을 처리하는 것입니다.   
- 코루틴 (Coroutine)무겁고 느린 공룡 같은 전통적인 일꾼(Thread) 대신, 가볍고 날렵하게 날아다니는 작은 새 같은 존재예요. 
  일이 끝날 때까지 자리를 떡하니 차지하고 멈춰 있는(Blocking) 것이 아니라, 잠시 쉬어야 할 때(Suspend) 자리를 다른 일꾼에게 
  양보하고 나중에 다시 쏙 이어받는(Resume) 아주 똑똑한 비동기 마법 기술입니다.
  
- 구조화된 동시성 (Structured Concurrency):
  코루틴들이 제멋대로 돌아다니지 않고 울타리(Scope) 안에서 안전하게 생성되고 종료되도록 관리하는 규칙입니다. 
  메모리 누수를 막아줍니다.   
- 코루틴 빌더 (launch, async):
  새로운 코루틴을 만들어 실행시키는 마법 명령어입니다. 
  결과값이 필요 없으면 launch, 나중에 결과를 받아와야 하면 async를 사용합니다.   
- Deferred와 await(): 
  async를 쓸 때 반환되는 미래의 값 상자(Deferred)이며, await()를 호출하면 그 상자 안의 결과를 쏙 꺼내올 수 있습니다.   
- 디스패처 (Dispatcher): 
  "이 작업은 계산 전문 일꾼에게 줘라(Default)", "저 작업은 파일/인터넷 통신 전문 일꾼에게 줘라(IO)" 하고 일꾼의 역할을 
  배정해 주는 스케줄러입니다.

-  정리.
  - 하나의 교사가 여러가지 일을 하는 것 (싱글 코어) ⇒ 동시성
  - 교사와 조교가 함께 일을 하는 것 (멀티 코어)    ⇒ 병렬성
  - 순서대로 실행하는 것   ⇒ 동기
  - 동시에 실행하는 것    ⇒ 비동기 (동시성, 병렬성을 모두 표현할 수 있음)

- delay()의 비밀: 
  그냥 멍하니 멈춰 있는 Thread.sleep()과 달리, delay()는 "나 잠깐 2초 동안 쉴 테니까, 
 그동안 내 일꾼 자리를 다른 친구(다른 작업)에게 양보할게!" 하고 똑똑하게 쉬는 기술이에요 (suspend 함수).
- 순차 vs 병렬의 차이:순차 실행(time1): 
  1초 + 1.5초 + 2초를 다 더해서 총 4.5초가 걸려요.
- 병렬 실행(time2): 
  async와 await를 쓰면 세 일이 동시에 진행되므로, 가장 오래 걸리는 2초 만에 끝나요! 
  시간이 훨씬 절약되죠

### 과제 내용
연습문제 1 풀이: 세 마리의 새가 각기 다른 간격으로 소리 내기 (4번만 출력)
설명: 1초, 2초, 3초마다 각각 "꾸우", "까악", "짹짹" 소리를 내는 세 개의 코루틴을 만들고, 
각각 정확히 4번씩만 소리를 낸 뒤 종료되도록 만드는 문제입니다.
// ---연습문제 1.---
fun main() = runBlocking {
// runBlocking은 코루틴이 모두 끝날 때까지 메인 프로그램을 잠시 멈춰주는 역할을 합니다.
    // 첫 번째 새: 1초마다 "꾸우" 소리를 4번 냅니다.
    val job1 = launch {
        repeat(4) { it -> // 4번 반복하는 반복문
            delay(1000L)  // 1초(1000밀리초) 동안 일시 정지 (스레드를 차단하지 않고 양보함)
            println("첫 번째 새: 꾸우 (${it + 1}번째)")
        }
    }
    // 두 번째 새: 2초마다 "까악" 소리를 4번 냅니다.
    val job2 = launch {
        repeat(4) { it ->
            delay(2000L)  // 2초 동안 일시 정지
            println("두 번째 새: 까악 (${it + 1}번째)")
        }
    }
    // 세 번째 새: 3초마다 "짹짹" 소리를 4번 냅니다.
    val job3 = launch {
        repeat(4) { it ->
            delay(3000L)  // 3초 동안 일시 정지
            println("마지막 새: 짹짹 (${it + 1}번째)")
        }
    }
    // 세 마리의 새(코루틴)가 모두 일을 마칠 때까지 기다려 줍니다.
    job1.join()
    job2.join()
    job3.join()    
    println("모든 새들이 노래를 마쳤습니다!")
}

import kotlinx.coroutines.*

fun main() = runBlocking {
// 첫 번째 새: 1초마다 무한히 "꾸우" 소리를 냅니다.
val job1 = launch {
var count = 1
while (true) { // 횟수 제한 없는 무한 루프
delay(1000L)
println("첫 번째 새: 꾸우 ($count)")
count++
}
}
// 연습문제 2: 무한히 소리 내는 새들을 10초 후에 일괄 취소하기
    // 두 번째 새: 2초마다 무한히 "까악" 소리를 냅니다.
    val job2 = launch {
        var count = 1
        while (true) {
            delay(2000L)
            println("두 번째 새: 까악 ($count)")
            count++
        }
    }
    // 세 번째 새: 3초마다 무한히 "짹짹" 소리를 냅니다.
    val job3 = launch {
        var count = 1
        while (true) {
            delay(3000L)
            println("마지막 새: 짹짹 ($count)")
            count++
        }
    }
    // 메인 프로그램에서 10초(10000밀리초) 동안 기다립니다.
    delay(10000L)
    // 10초가 지나면 Job 객체의 cancel() 함수를 이용해 실행 중인 모든 코루틴을 강제로 취소합니다[cite: 15]!
    job1.cancel()
    job2.cancel()
    job3.cancel()
    println("10초가 지나서 모든 새들의 노래를 중단시켰습니다!")
}

- 코루틴(Coroutine)과 suspend 함수의 원리
  무겁고 다루기 힘든 자바의 스레드(Thread) 대신, 가볍고 유연하게 움직이는 코루틴의 개념.
  Thread.sleep()처럼 일꾼을 꽁꽁 묶어두는 방식이 아니라, 
  delay()를 통해 일꾼이 잠시 쉬는 동안 다른 작업에 자리를 양보하는 중단(Suspend)과 재개(Resume) 메커니즘.   
- 순차 실행과 병렬 실행의 성능 최적화
  - task1, task2, task3 같은 비동기 함수들을 순차적으로 실행할 때와, 
  - async와 await()를 조합하여 병렬로 실행할 때의 소요 시간을 비교하며 성능 향상 효과를 직접 확인했습니다.   
  - measureTimeMillis를 활용해 실행 시간을 측정하고, 가장 오래 걸리는 작업 시간을 기준으로 전체 소요 시간이 단축되는 병렬 처리의 
    장점을 파악했습니다.   
- 코루틴 제어와 구조화된 동시성
  - Job 객체와 cancelAndJoin()을 통해 실행 중인 무한 반복 코루틴을 안전하게 취소하고 제어하는 방법을
    실습했습니다.   
  - 코루틴 울타리(CoroutineScope) 안에서 수명이 관리되는 구조화된 동시성을 통해 메모리 누수를 방지하고 코드를 안전하게 작성하는 
    규칙을 다졌습니다.
