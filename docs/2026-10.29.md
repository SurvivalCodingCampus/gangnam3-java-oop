## 1. 배운 점
-  인터넷 우체부, 네트워크 통신: 컴퓨터끼리 편지(데이터)를 주고받는 규칙을 배우는 시간이에요.   
- HTTP와 JSON:
  -  HTTP와 인터넷: 우리가 인터넷 브라우저로 웹사이트에 접속하거나 사진을 볼 때 
     컴퓨터끼리 대화하는 규칙(약속)이에요. 요청(Request)을 보내면 서버가 응답(Response)을 
     주는 1:1 구조로 이루어져 있습니다.

  -  JSON: 서버와 클라이언트가 데이터를 주고받을 때 사용하는 전 세계 공통의 가벼운 대화 상자(데이터 형식)예요.
     이름과 값(Key-Value) 형태로 이루어져 있어 사람이 읽기에도 아주 쉽습니다.

-  RESTful API: 인터넷 상에서 데이터를 조회하고, 만들고, 수정하고, 삭제(GET, POST, PUT, PATCH, DELETE)
   할 때 지키는 전 세계적인 암묵적 규칙(설계 규격)입니다.

-  Ktor 클라이언트: 코틀린 언어로 인터넷 세상에 편지를 보내고 받아올 수 있게 도와주는 멋진 마법 우체국 라이브러리입니다.

### 주요 명령어 및 개념 정리
-  HttpClient: 인터넷 서버와 통신하기 위해 우체부 역할을 해주는 핵심 객체입니다.   
-  client.get(url): 서버에 데이터를 읽어오라고 요청(GET)하는 명령어입니다.   
-  client.post(url): 서버에 새로운 데이터를 보내어 생성해 달라고 요청(POST)하는 명령어입니다.   
-  ByteArray: 글자나 그림 등 컴퓨터가 이해할 수 있는 가장 원초적인 0과 1의 데이터 묶음(바이트 배열)입니다. 
   파일이나 사진을 다운로드할 때 주로 사용합니다.   
- delay / suspend: 인터넷에서 데이터를 가져오는 동안 프로그램이 멈추지 않고 다른 일을 할 수 있게 도와주는 
  코루틴 마법 기술입니다.

### 첨부파일 요약
- 컴퓨터들의 전화선, 소켓(Socket)과 TCP/UDP:
  - 컴퓨터끼리 대화할 때 쓰는 기초적인 통신 방법을 '소켓'이라고 해요.   
  - TCP: 편지를 보낼 때 우체국 등기우편처럼 "상대방이 잘 받았는지 꼭 확인하며 튼튼하게 연결해서 대화하는 방식"이에요. 
         이메일이나 웹사이트를 볼 때 씁니다.   
  - UDP: 택배를 보낼 때 전단지를 공중에 뿌리듯, 확인 절차는 없지만 "엄청나게 빠르고 신속하게 데이터를 던지는 방식"이에요. 
         주로 실시간 게임이나 방송을 할 때 씁니다.   
  - 서버에게 일 시키는 법, HTTP 요청 메서드:
    우리가 인터넷으로 무언가를 하거나 살 때 서버에 보내는 '주문서의 종류'라고 
    생각하면 돼요.   데이터를 읽어올지, 새로 만들지, 고칠지에 따라 알맞은 이름을 써야 합니다.   
  - 상태 코드와 쿠키:
    서버에게 요청을 보냈을 때 "200 OK(성공!)", "404 Not Found(페이지가 없어요!)"처럼 현재 상태를 숫자로 알려주는 신호가 
    상태 코드예요.   
  - 쿠키는 인터넷 세상에서 내가 누군지 기억해 주는 디지털 명함 같은 것이랍니다.   


###  AI 질문 및 학습인사이트(공통)
-  AI에게 핵심 질문(Prompt): 오늘 강의 주요 명령어 및 개념 정리해줘.

### 주요 명령어 및 개념 정리
-  socket(): 컴퓨터와 컴퓨터가 통신하기 위해 전화 연결용 수화기를 드는 명령어
-  connect(): 클라이언트(손님 컴퓨터)가 서버(가게 컴퓨터)에 연결을 요청하는 명령어.
-  GET: 서버에게 "데이터를 보여줘!" 하고 읽어오기를 요청하는 메서드
-  POST: 서버에게 "이 새로운 데이터를 저장해 줘!" 하고 데이터를 통째로 보낼 때 쓰는 메서드
-  PUT: 서버에 있는 기존 데이터를 "전부 다 새로운 것으로 바꿔서 업데이트해 줘!"
-  PATCH: 기존 데이터 중에서 "일부 페이지만 쏙 골라서 살짝 고쳐줘!"
-  DELETE: 서버에 있는 데이터를 "삭제해 줘!"

### 과제 내용
-  연습문제 4번 풀이 (사진 다운로드 및 저장 기능 구현)
        package com.survivalcoding.network

        import io.ktor.client.*
            import io.ktor.client.request.*
        import io.ktor.client.statement.*
        import kotlinx.coroutines.Dispatchers
        import kotlinx.coroutines.withContext
        import java.io.File

        // 1. [ImageDataSource 인터페이스]: 사진을 인터넷에서 다운받고 저장하는 기술적 세부사항 정의
         interface ImageDataSource {
        // URL을 통해 인터넷에서 이미지를 다운로드하여 바이트 배열(ByteArray)로 반환
        suspend fun fetchImage(url: String): ByteArray

         // 바이트 배열 데이터를 받아 지정된 경로(path)에 파일로 저장
        suspend fun saveImage(bytes: ByteArray, path: String)
        }

         // 2. [ImageDataSourceImpl 구현체]: Ktor 클라이언트를 이용해 실제 네트워크 통신과 파일 저장을 수행
         class ImageDataSourceImpl(
        private val client: HttpClient // 인터넷 통신을 위한 Ktor 클라이언트 주입
        ) : ImageDataSource {

        override suspend fun fetchImage(url: String): ByteArray {
        // 클라이언트를 통해 GET 요청을 보내고, 응답 데이터를 바이트 배열(ByteArray)로 변환하여 반환
            return client.get(url).bodyAsBytes()
         }

        override suspend fun saveImage(bytes: ByteArray, path: String) {
        // 파일 입출력은 디스크를 사용하는 무거운 작업이므로 IO 전용 일꾼(Dispatchers.IO)에게 시킴
             withContext(Dispatchers.IO) {
                File(path).writeBytes(bytes) // 받아온 바이트 배열을 지정된 경로의 파일로 씀
                }
            }
        }

        // 3. [ImageRepository 인터페이스]: 비즈니스 로직(이미지 저장, 중복 확인 등)을 위한 창구 정의
        interface ImageRepository {
        // URL에서 이미지를 다운로드하여 지정된 경로에 저장
        suspend fun saveImage(url: String, path: String)

        // 여러 URL의 이미지들을 지정된 디렉토리에 순차적으로 저장
        suspend fun saveImages(urls: List<String>, directory: String)

        // 이미지가 존재하지 않는 경우에만 URL에서 다운로드하여 저장 (성공하면 true, 이미 있으면 false 반환)
        suspend fun saveImageIfNotExists(url: String, path: String): Boolean
         }

         // 4. [ImageRepositoryImpl 구현체]: DataSource를 주입받아 구체적인 비즈니스 규칙 처리
        class ImageRepositoryImpl(
            private val imageDataSource: ImageDataSource // 데이터소스를 생성자로 주입받음
            ) : ImageRepository {

        override suspend fun saveImage(url: String, path: String) {
        // 1. DataSource를 통해 인터넷에서 이미지 데이터를 ByteArray로 다운로드
        val imageBytes = imageDataSource.fetchImage(url)
        // 2. 다운로드받은 데이터를 지정된 경로에 파일로 저장
        imageDataSource.saveImage(imageBytes, path)
    }

         override suspend fun saveImages(urls: List<String>, directory: String) {
        // 리스트에 있는 모든 URL을 하나씩 순회하며 이미지 다운로드 및 저장 수행
        urls.forEachIndexed { index, url ->
            val path = "$directory/image_$index.jpg" // 파일 이름 자동 생성
                saveImage(url, path)
         }
        }

        override suspend fun saveImageIfNotExists(url: String, path: String): Boolean {
        val file = File(path)
        // 만약 해당 경로에 파일이 이미 존재한다면 다운로드하지 않고 false 반환
        if (file.exists()) {
            return false
        }
        
        // 파일이 존재하지 않는 경우에만 다운로드 후 저장하고 true 반환
        val imageBytes = imageDataSource.fetchImage(url)
        imageDataSource.saveImage(imageBytes, path)
        return true
    }
}
