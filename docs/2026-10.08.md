1. Enum은 왜 쓸까요? (상수 관리의 필요성)
   프로그램을 만들다 보면 요일, 계절, 회원 등급, 상태 값처럼 정해진 몇 가지 값만 허용해야 하는 경우가 많습니다.

    만약 이를 일반적인 문자열이나 숫자로 처리한다면 아래와 같은 문제가 생깁니다.
    오타 발생: "ADMIN", "admin", "admiin"처럼 실수로 다른 값을 적어도 컴파일러가 잡아내지 못합니다.
    의미 파악의 어려움: 코딩 중에 1, 2, 3 같은 숫자가 무엇을 의미하는지 알기 어렵습니다.
    Enum을 사용하면 이 모든 문제를 해결하고, 코드를 안전하고 명확하게 유지할 수 있습니다.

2. 기본적인 사용법 (자바 기준)
   Enum은 enum 키워드를 사용하여 정의합니다. 보통 대문자로 상수를 나열하는 것이 관례입니다.

3. Enum의 강력한 기능 🌟
   Enum은 단순한 상수 모음이 아니라 '클래스'이기 때문에 내부에 변수나 메서드를 가질 수 있어 훨씬 강력하게 활용됩니다.
   ① 값(상태)과 함께 사용하기
     각 상수마다 고유한 값이나 설명을 연결하고 싶을 때 생성자를 활용할 수 있습니다.
   ② switch 문과의 궁합 (조건 분기)
     switch 문에서 Enum을 사용하면 가독성이 엄청나게 좋아집니다.

4. 알아두면 유용한 기본 제공 메서드
   Enum 클래스는 자바에서 기본적으로 강력한 편의 메서드들을 제공합니다.

   values(): Enum에 속한 모든 상수를 배열(Day[])로 반환합니다.
   valueOf(String name): 문자열과 일치하는 Enum 상수를 반환합니다.
   (예: Day.valueOf("MONDAY"))
   ordinal(): 상수가 정의된 순서(0부터 시작)를 숫자로 반환합니다. 
   (단, 순서가 바뀌면 값이 달라지므로 로직에는 되도록 사용하지 않는 것이 좋습니다.)

        fun isVowel(i: Int): Boolean {
        // i번째 글자 한 글자를 잘라냅니다.

 연습문제 2.
    class Word(var word: String) {
        fun isVowel(i: Int): Boolean {
        val letter = word.substring(i, i + 1)
        return letter == "a" || letter == "e" || letter == "i" || letter == "o" || letter == "u"
        }

        fun isConsonant(i: Int): Boolean {
        // 모음이 아니라면 자음입니다! (isVowel의 결과가 거짓이면 참)
        return !isVowel(i)
        }
    }

- 옛날 자바 방식보다 코틀린에서는 돈 기호($) 하나만 붙이면 되는 문자열 보간법(String interpolation)을 
   써서 훨씬 쉽고 예쁘게 글자를 합칠 수 있어요.
   예: "Hello $name" 하면 이름이 쏙 들어갑니다.

- 글자 자르고 바꾸기
  자르기 (substring): "Hello"에서 앞에서부터 2글자만 싹둑 자르면 "He"가 돼요.
  바꾸기 (replace): "HELLO"에서 "LL"을 찾아서 "XX"로 바꾸면 "HEXXO"가 됩니다.
  쪼개기 (split): "1,2,3"을 콤마(,) 기준으로 싹둑싹둑 썰어서 ["1", "2", "3"] 처럼 여러 조각으로 나눌 수 있어요.
  대소문자 바꾸기: 영어 대문자를 전부 소문자로(lowercase), 소문자를 대문자로(uppercase) 바꿀 수도 있어요.
  왜 + 연산보다 StringBuilder가 더 빠를까?
  코틀린의 글자(String)는 한 번 만들어지면 고쳐쓸 수 없는 불변(Immutable) 성질이 있어요. 그래서 + 기호로 글자를 계속 
  더하면 매번 새로운 글자 상자를 계속 만드느라 컴퓨터가 헉헉대며 느려져요.
  반면 StringBuilder는 커다란 작업 상자(버퍼)를 하나 펴놓고 그 안에 글자를 계속 쌓은 다음에 마지막에 딱 보여주기 때문에 훨씬 빨라요!
