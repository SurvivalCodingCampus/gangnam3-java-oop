## 용어정리

### List, Map, Set

- key,vale의 쌍이 있다면 Map
- 중복이 가능해야 한다면 List
- 중복이 불가하다면 Set
- 순서대로 쌓이는 List라 순서가 중요하다면 List
- 순서가 중요하지 않다면 Set
- 정해진 검색 속도 안에서 검색해야 한다면 Set

### 별들의 전쟁 개발 기획

- is-a는 추상화 클래스 can-do는 인터페이스 하단 클래스가 가지는 유일한 메소드는 오버라이드로 처리
- 모든 종족이 공통적으로 가지고 있는 유닛과 건물을 추상화 클래스로 처리하고 bio와 mechanic을 클래스가 아닌 인터페이스로 처리하는 것이 신의 한수였던거 같다.
- 인터페이스의 모든 가능성을 리스트화한 다음에 클래스와 연결하고 공통점을 가지고 있는 상위 클래스로 올리는 방법으로 해결함
