# 인스턴스와 클래스
- 클래스 = 설계도
- 오브젝트(Object)는 프로그래밍에서 아주 중요한 개념. 설계도로 실제 만든 물건, 오브젝트 = 속성(Data) + 기능(Method)
- 인스턴스(Instance)는 객체(Object)와 거의 같은 의미로 사용되지만, 어떤 클래스에서 만들어졌는지를 강조하는 표현

## 용어 정리
- 캡슐화 Encapsulation
데이터와 기능을 하나로 묶고, 필요한 부분만 외부에 공개

- 상속 Inheritance
기존 클래스의 기능을 물려받는 것입니다.

- 다형성 Polymorphism
같은 명령이 객체에 따라 다르게 동작하는 것입니다.

- 추상화 Abstraction
복잡한 내부 구조를 숨기고 사용자에게 필요한 기능만 보여주는 것입니다.

- 인스턴스(Instance)는 객체(Object)와 거의 같은 의미로 사용되지만, 어떤 클래스에서 만들어졌는지를 강조하는 표현

## 클래스 작성 핵심 코드
``````java
public class Cleric {

    // 성직자의 이름
    String name;

    // HP
    int hp;

    // 최대 HP 
    final int MAX_HP = 50;

    // MP
    int mp;

    // 최대 MP 
    final int MAX_MP = 10;
}
