## 1. 배운 점

### Java

- 1. 모든 클래스는 Object 클래스의 메서드를 가지고 있다
- 2. Object 타입 변수에는 모든 인스턴스를 대입할 수 있다
     <Object 클래스의 대표 메서드>
      -  toString() : 문자열 표현을 얻음
      -  equals() : 비교
      -  hashCode() : 해시값을 얻음
- 3. equals() 메서드를 오버라이드하여 동등성 규칙을 정의할
      수 있음 List에서 동등성 비교시 사용됨.
- 4. Set, Map의 동작원리
     Set, Map 계열은 요소를 검색할 때 equals() 보다 비용이 싼 hashCode() 비교를 사용함
     List 는 순차 검색이라 느림.
     a 모든 객체는 해시값을 가진다
     b. 동일한 객체는 항상 같은 해시값을 가진다.
     c. 하지만, 같은 해시값이라고 항상 동일한 객체는 아니다.
- 5. 리스트에서 요소정렬.
     - Collections.sort() 메서드는 컬렉션 내부를 정렬해 줌
- 6. 정렬이 수행될 객체의 기준
     - Collections.sort() 메서드의 선언은 다음과 같음
     - 정렬 규칙을 정하기 위한 Comparable 인터페이스
- 7. Comparable 인터페이스 구현.
     - 정렬대상은 반드시 Comparable인터페이스를 구현해야 함.
- 8. Comparator 인터페이스 구현.
     - 런타임에 정렬 규칙을 정하기 위한.
- 9. 얕은복사(Shallow Copy)
     - 객체 자체는 새로 생성되지만, 객체 내의 참조 타입 필드(다른 객체에 대한 참조)는 원본과 동일한 객체를 참조합니다.
     - 즉, 중첩된 객체는 복사되지 않고 주소만 복사됩니다.
     - 원본 객체의 참조 타입 필드를 변경하면 복사본의 해당 필드도 함께 변경됩니다.
- 10. 깊은복사(deep copy)
     - 객체 자체뿐만 아니라, 객체 내의 모든 참조 타입 필드(중첩된 객체들)까지도 재귀적으로 완전히 새로 생성하여 복사합니다.
     - 원본 객체와 복사본 객체는 완전히 독립적입니다. 한쪽을 변경해도 다른 쪽에는 영향을 주지 않습니다.

   객체의 내용을 알기 쉽게 보여주기 위해 다음 메서드를 재정의 해 준다
          toString()

        객체의 동등성 비교 규칙을 위해 다음 메서드를 재정의 해 준다
          equals
          hashCode

        복사를 지원하기 위해 다음 메서드를 작성한다.
          - Cloneable 인터페이스를 구현하여 얕은 복사를 구현하기로 한다

#### 나의 눈높이 설명.
우리가 만든 로봇(Hero)이나 책 같은 물건(Object)을 자바 세상에서는 인스턴스(객체)라고 불러요. 이 물건들을 다룰 
때 꼭 알아야 할 4가지 대장 규칙이 있답니다.
-  1. toString() — "나를 소개해줘!"뜻: 로봇을 화면에 출력하면 이상한 
      글자(Hero@1a2b3c)가 나와요. 이건 로봇의 '주민등록번호 암호' 같은 거예요.쉽게 이해하기: "내 이름은 슈퍼맨이고, 
      체력은 100이야!"라고 사람이 알아보기 쉽게 말해주는 기능으로 고쳐주는(오버라이드) 것이 바로 toString()이에요.   
-  2. equals()와 hashCode() — "우리가 진짜 똑같은지 확인해 볼까?"뜻: 이름과 체력이 똑같은 슈퍼맨 로봇 두 개가 있어요.
      자바에게 "이 둘이 같니?" 물어보면 기본적으로는 "달라!"라고 해요 (주소값이 다르거든요).
      쉽게 이해하기:equals(): "이름이랑 체력이 같으면 같은 로봇으로 쳐주자!"라고 기준을 정해주는 것이에요.   
      hashCode(): 자바의 Set이나 Map 같은 장바구니에 물건을 넣을 때, 일일이 다 비교하면 너무 느려요. 
      그래서 물건마다 '번호표(해시값)'를 붙여서 빠르게 찾게 도와주는 짝꿍 기능이에요.   
-  3. 정렬하기 (Comparable / Comparator) — "줄을 세워라!"뜻: 게임 점수나 키 순서대로 로봇들을 쫙 줄 세우고 싶을
      때가 있죠?쉽게 이해하기:Comparable은 로봇 스스로 "난 내 체력 순서대로 줄 서겠어!" 하고 기본 규칙을 정하는 것이고,
      Comparator는 "이번엔 특별히 이름 순서대로 줄 세워보자!" 하고 즉석에서 규칙표를 만들어주는 거예요.   비교할 때 앞의
      것이 작으면 -1(앞으로), 같으면 0, 크면 1(뒤로)을 보내서 자리를 찾아가요.
-  4. 복사하기 (얕은 복사 vs 깊은 복사) 
       — "장난감 복사기"뜻: 로봇을 복사할 때의 차이에요.쉽게 이해하기:얕은 복사 (Shallow Copy): 로봇 껍데기만 복사하고, 
      로봇이 들고 있는 '칼'은 원본이랑 똑같은 칼을 같이 바라보게 해요. 원본 로봇이 칼을 빨간색으로 칠하면 복사본 로봇의
      칼도 빨간색으로 변해요! (위험해요 ⚠️)   깊은 복사 (Deep Copy): 로봇 껍데기는 물론이고, 들고 있는 칼까지 똑같이
      하나 더 새로 복사해서 쥐여주는 거예요. 이제 둘은 완전히 따로 노는 독립된 로봇이 돼요!
