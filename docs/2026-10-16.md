# 디버깅 / 람다식과 함수

## 용어 정리

- `디버깅`: 소프트웨어의 오류를 식별하고 수정하는 과정
- `1급 객체`: 변수에 대입 가능한 객체. 대표적으로는 `값` `인스턴스` `함수` 가 있다.
- `익명 함수`: 이름이 없는 함수
- `람다 표현식`: 함수를 간결하게 표현하기 위해 사용되는 문법
- `콜백`: 나중에 실행될 코드를 미리 등록해 두는 것
- `함수형 프로그래밍`: 자료 처리를 수학적 함수의 계산으로 취급하는 프로그래밍 패러다임. 가변 데이터를 멀리한다.
- `고계 함수`: 함수를 다루는 함수 (함수를 파라미터로 받는 함수)

## 클래스 작성 테스트 코드

```kotlin
@DisplayName("Chart 직렬화 테스트")
class ChartTest {

    private lateinit var chart: Chart

    @BeforeEach
    fun setUp() {
        chart = Chart(
            listOf(
                CollectionChartData(
                    "collection1",
                    listOf(
                        CollectionSalePrice("2023-03-26T08:00:00", 58.25),
                        CollectionSalePrice("2023-03-26T08:00:10", 58.5),
                    )
                ),
                CollectionChartData("collection2"),
            )
        )
    }

    @Test
    fun `중첩된 JSON 문자열을 역직렬화하면 Chart 객체가 된다`() {
        // given
        val json = """
            {
              "collectionChartDataList": [
                {
                  "collectionName": "collection1",
                  "collectionSalePrice": [
                    { "price": 58.25, "cvtDatetime": "2023-03-26T08:00:00" }
                  ]
                }
              ]
            }
        """.trimIndent()

        // when
        val result = Json.decodeFromString<Chart>(json)

        // then
        val chartData = result.collectionChartDataList[0]
        assertEquals("collection1", chartData.collectionName)
        assertEquals("2023-03-26T08:00:00", chartData.collectionSalePrice!![0].cvtDatetime)
        assertEquals(58.25, chartData.collectionSalePrice[0].price)
    }

    @Test
    fun `collectionSalePrice가 없는 JSON을 역직렬화하면 collectionSalePrice는 null이다`() {
        // given
        val json = """{"collectionName":"collection75"}"""

        // when
        val result = Json.decodeFromString<CollectionChartData>(json)

        // then
        assertEquals("collection75", result.collectionName)
        assertNull(result.collectionSalePrice)
    }

    @Test
    fun `직렬화한 뒤 다시 역직렬화하면 원래 객체와 같다`() {
        // when
        val json = Json.encodeToString(chart)
        val result = Json.decodeFromString<Chart>(json)

        // then
        assertEquals(chart, result)
    }

    @Test
    fun `직렬화한 JSON을 파일에 쓰고 다시 읽어 역직렬화하면 원래 객체와 같다`(@TempDir tempDir: File) {
        // given
        val file = File(tempDir, "test_chart.json")
        val json = Json.encodeToString(chart)

        // when
        file.writeText(json)
        val result = Json.decodeFromString<Chart>(file.readText())

        // then
        assertTrue(file.exists())
        assertEquals(chart, result)
    }

    @Test
    fun `chart_data json 파일을 역직렬화하면 collectionSalePrice가 없는 컬렉션은 null이다`() {
        // given
        val file = File("src/main/java/com/survivalcoding/day10_debugging/chart_data.json")

        // when
        val result = Json.decodeFromString<Chart>(file.readText())

        // then
        assertEquals(75, result.collectionChartDataList.size)
        assertEquals(1, result.collectionChartDataList.count { it.collectionSalePrice == null })
    }
}
```

## 정리

- `디버깅의 중요성`
  - `디버깅` 은 소프트웨어가 올바르게 작동하는지 확인하는 데 필수적이다.
  - `디버깅` 을 하지 않으면 소프트웨어가 오류가 발생하거나 제대로 작동하지 않을 수 있다.

- `디버깅 기술`
  - `로깅`: 코드가 실행되는 동안 발생하는 이벤트를 기록하는 데 사용
  - `브레이크 포인트`: 코드의 특정 지점에서 실행을 중지하는 데 사용
  - `디버거`: `디버깅` 을 도와주는 도구. 다양한 기능을 제공하며 `디버깅` 을 더 쉽게 만들 수 있다.
  - `스택 추적`: 호출 스택을 추적하여 코드가 실행 중인 위치를 확인하는 데 사용

- `디버깅 팁`
  - `작게 시작`: `디버깅` 을 할 때는 작은 문제부터 시작하는 것이 중요하다. 더 큰 문제로 넘어가기 전에 한번에 한 가지 문제에 집중하도록 한다.
  - `단순하게 유지`: `디버깅` 을 할 때 코드를 단순하게 유지하는 것이 중요하다. 오류의 원인을 파악하기가 용이하다.
  - `인내심`: `디버깅` 은 시간이 많이 걸릴 수 있는 작업이다. 오류를 찾지 못해도 낙심하지 않고 여유를 가진다.

- `함수의 표현 방법`
  - `단일 매개변수 람다`: `람다` 의 매개변수가 하나인 경우, 매개변수를 생략하고 `it` 을 사용할 수 있다.
  - `후행 람다`: 함수의 마지막 인자가 `람다` 일 경우, 함수 호출 소괄호 밖에 `람다` 를 작성할 수 있다.

- `메서드와 함수의 차이`
  - `메서드` 는 클래스에 속하고 클래스를 조작하기 위한 일종의 함수
  - `메서드` 는 이름이 있지만, `함수` 에게 이름은 중요치 않다.

- `Kotlin 에서 제공되는 대표적인 고계 함수`
  - `filter`: 조건 필터링. 조건에 해당하는 요소만 가지는 새로운 컬렉션을 생성한다.
  - `map`: 변환. 변환된 새로운 컬렉션을 생성한다.
  - `toSet`: 자료구조 `Set` 으로 변환하는 함수. 중복을 허용하지 않기 때문에 중복 데이터를 제거할 수 있다.
  - `forEach`: 전체 순회
  - `reduce`: 하나씩 줄이기. 반복 요소를 줄여가면서 결과를 만들 때 사용하는 함수
  - `fold`: 하나씩 접기
  - `any`: 있는지 없는지 조회. 특정 조건을 충족하는 요소가 있는지를 검사할 때 사용한다.

- `안티패턴의 조건`
  - 함수형 프로그래밍의 의도 위반
    - `forEach`: 각 요소에 대한 동작을 모두 수행한다.
    - `map`: 변환된 새 컬렉션을 생성한다.
  - 코드의 예측 가능성 저하
  - 부작용(Side Effect) 발생 가능
  - 가독성 저하
  - 유지보수 어려움
